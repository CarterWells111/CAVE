- 可选 AI 继续写、整理、回顾、旅程问答。逐次确认所选内容；结果需主动采用；取消/改文/换账号不沿用过期结果。
- 服务端 DeepSeek 兼容接口、会话鉴权、限流、请求/响应大小限制、超时、来源与输出检查；不保存正文或写正文日志。

## 打开验收版

使用与 Expo SDK 57 匹配的 Expo Go。电脑与手机连接同一网络。

当前预览：`exp://172.20.10.3:8083`。可用 Expo Go 扫描交付的二维码。此地址只在当前电脑和网络、开发服务运行期间有效。

重新启动：在仓库根目录使用符合项目要求的 Node 22/24，执行：

```sh
corepack pnpm --filter @cave/mobile start:journal-preview --lan --port 8083
```

此命令仅启动 Metro / Expo Go 开发服务，设置本机模拟模式；不产生原生安装包，不调用 DeepSeek。邮箱登录沿用现有 Gateway，必须使用测试账号。请只输入合成测试文字，Expo Go 手记库未使用 SQLCipher 加密。

## 手机验收清单

| 操作 | 预期结果 |
| --- | --- |
| 首次进入，确认显示旅程；切换内界手记，点击开始写手记 | 完成年满 18 岁声明并登录即可进入，无须完成旅程前言 |

| 打开已保存记录，修改；查看修改历史 | 新内容可见，修改前内容作为旧版本保留；超过 24 小时也能编辑 |
| 增加一个后来，再修改或删除 | 时间线显示变化；删除后的后来及其历史不再显示 |
| 内界手记 → 回顾一段时间 → 切换一周/月/自选日期 | 仅显示范围内记录，可选定记录并写小结，能回到原记录 |
| 编辑页 → 帮我整理 | 先出现本次内容预览；未确认前没有结果 |
| 确认运行本机模拟 | 明确显示“模拟结果 · 未调用真实模型”；正文尚未改变 |
| 点击“符合，放入编辑区”，再保存 | 提议进入可编辑正文，用户可以修改后保存 |
| 回顾选择记录后点击帮我回顾 | 预览仅含选定记录与后来，模拟结果的出处按钮能打开原记录 |
| AI → 旅程问答，输入“做到一半想暂停，可以吗？” | 可走问题预览与模拟回应流程，不自动读取手记 |
| 换账号或取消；修改已预览的原文 | 不沿用之前的确认或结果；普通本机记录不依赖 AI |
