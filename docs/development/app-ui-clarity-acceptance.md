## 人工检查（使用合成数据）
| 场景 | 通过标准 |
| --- | --- |
| 首次启动与成年声明 | 品牌与必要声明保留；拒绝、返回、恢复路径保持可用 |
| 五栏导航 | 旅程、房间、内界手记、AI、我的均可到达，选中状态正确 |
| 旅程首页 | 原有地图节点、顺序和连接关系保持；工具入口不堆在页标题之前 |
| 页面帮助 | 页首一般说明不再重复出现；右上图标打开完整可滚动帮助，关闭后页面状态不丢失 |
| 小屏与大字体 | 320/375 宽度及系统大字体下文字可读、按钮至少 44×44；五栏标签不被固定高度裁切 |
| 主题 | 深浅主题均沿用现有配色，主要操作与次要文字清晰 |
| 手记 | 新建、恢复草稿、搜索、专题筛选、原记录、后来、回顾均可到达；类型选择取消不修改原选择 |
| 房间 | 单人/双人、创建/加入、邀请、逐题保存、双方完成与同意、报告工具及结束确认均可用 |
| 网络错误 | 房间未开放、请求失败、AI 用量不足及过期登录仍显示真实状态并可恢复 |
| AI | 建议仅填入输入框；发送前确认、私密内容确认、停止、重试及额度入口保持可用 |
| 我的与设置 | 账号、归档、外观与删除入口不丢失，导航行不嵌套第二个打开按钮 |
| 键盘与安全区 | 编辑与聊天输入不被键盘、底部栏或安全区遮挡；最后一项可滚动到达 |
| 读屏 | 标题、帮助、导航行和单选项名称清晰，选择状态可读；弹层关闭后焦点恢复 |
