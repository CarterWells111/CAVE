# 本机账号资料与登录入口设计

## 目标

在不上传日记、沟通卡、回顾或账号资料的前提下，为登录状态提供一致、可辨识的本机账号体验：完成首次旅程后的首页提供登录入口，“我的”展示账号身份，设置页允许修改头像和昵称。

## 产品行为

### 首页

- 未登录：原顶部“大设置”按钮改为“去登录，享受更多功能”，进入邮箱登录页。
- 已登录或离线会话可用：显示简洁的已登录账号入口，不重复催促登录；点击进入“我的”。
- 登录状态加载中：入口不可操作并显示检查状态。
- 设置仍从“我的”页右上角进入。

### “我的”页

- 账号卡位于“内界手记”上方。
- 未登录：显示默认头像和“邮箱登录”按钮。
- 已登录或离线：显示本机头像、昵称和登录邮箱；此处只读。
- 账号卡、按钮及文字全部使用主题色，支持亮色和暗色模式。

### 设置页

- 顶部账号卡复用“我的”页的账号信息。
- 已登录：头像上覆盖“点击更改”；点击后可从相册选择图片，或恢复默认头像。昵称右侧显示铅笔按钮，点击后打开昵称编辑框。
- 未登录：显示默认头像和邮箱登录按钮，不显示无效的编辑入口。
- 邮箱只读。更换邮箱需退出当前账号后登录另一个账号。
- 保留现有“账户与保存”、隐私说明、外观和删除能力，但避免重复显示互相矛盾的登录按钮。

## 数据设计

- 服务器继续只返回 `accountId` 和令牌，不新增云端资料接口。
- 登录验证成功后，移动端把规范化邮箱加入本机安全会话记录；刷新会话时沿用本机已保存邮箱。
- 本机账号资料按 `accountId` 隔离，字段为 `displayName`、可选 `avatarUri`、`updatedAt`。
- 昵称默认值为“内界用户”。保存前去除首尾空格，限制为 1–24 个 Unicode 字符；空昵称不能保存。
- 相册图片复制到 App 私有文档目录后再保存 URI，不能依赖系统临时资源路径。
- 退出登录只清除当前会话，不删除账号资料或内容；同一账号再次登录可恢复资料。
- 删除全部本机数据必须同时删除所有本机账号资料和私有头像文件。
- 删除云端账号后清除该账号会话；本机内容和资料继续遵循现有独立删除口径，不隐式删除。

## 组件与数据流

- 新增可复用 `AccountProfileCard`，接收账号状态、邮箱、昵称、头像 URI 及可选编辑回调。
- 新增本机 `AccountProfileRepository`，负责按账号读取、保存、恢复默认头像及全部清理。
- 新增 Provider 在认证状态或 `accountId` 变化时读取对应资料，并向首页、“我的”和设置提供统一状态。
- 图片选择通过 Expo 官方图片选择器；选择成功后由资料层复制并替换旧头像文件。
- 邮箱登录流程在发起挑战时暂存规范化邮箱，验证成功时与会话一并落入 SecureStore；不写入 D1、日志或埋点。

## 错误与边界

- 用户取消选图不显示错误，也不改变头像。
- 图片复制、昵称保存失败时保留旧值并显示可重试的中性提示，不泄露文件路径。
- 离线但本机会话有效时可以查看和修改本机资料。
- 登录状态尚未确定时不短暂显示其他账号资料。
- 资料损坏时回退为默认昵称和默认头像，不影响登录及私密内容。

## 测试与验收

- 首页针对加载、未登录、已登录/离线状态验证文案、路由和不重复催促。
- “我的”页验证账号卡位于手记之前，未登录和已登录状态正确。
- 设置页验证头像选择/恢复、昵称编辑/校验、邮箱只读和暗色模式可读性。
- Repository 验证账号隔离、持久化、替换旧头像和全部本机数据清理。
- Auth 验证登录邮箱只保存在本机会话、刷新不丢失、退出后不暴露。
- 真机验收相册权限、头像持久化、重启恢复、切换账号隔离和暗色模式。

## 非目标

- 不做云端头像、昵称或邮箱资料同步。
- 不允许在资料页直接更换登录邮箱。
- 不新增社交关系、公开主页或内容上传。
