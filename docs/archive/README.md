# 历史资料归档

本目录保存内界 CAVE 在黑客松期间形成的历史资料，包括旧产品方案、实现计划、阶段验收、内容运营和展示准备记录。

这些文件用于保留决策演变和工程过程，不作为当前产品范围、运行状态或发布结论的依据。当前信息以根目录 [README](../../README.md) 和[现行文档导航](../README.md)为准。

## 目录

- `development-history/`：历史实现计划、设计规格和协作记录。
- `product-history/`：已被现行五页旅程与独立练习入口取代的旧产品与界面方案。
- `quality-history/`：绑定旧分支、旧提交或阶段性环境的验证记录。
- `demo-day/`：展示准备、话术和差距分析。
- `content-history/`：内容运营与内部复核准备材料。

归档文件保留原始口吻、路径和状态，以便理解当时的上下文；引用其中结论前应回到现行文档和代码重新核对。
