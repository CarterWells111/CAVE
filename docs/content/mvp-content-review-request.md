# CAVE 七屏 MVP 内容复核请求

本轮只请复核内容是否准确、安全、自然且适合目标用户，不涉及程序、数据库或页面实现。

CAVE 面向 18—24 岁、第一次进入身体亲密关系的成年女性，同时包容不同性取向、伴侣性别与身体经验。产品不把共同过夜等同于发生性行为，不把插入视为亲密关系的默认路线，也不替用户判断是否“准备好了”。

请对每组回复：**批准 / 修改后批准 / 不使用**。如需修改，请直接提供替换文案。文中的“你”是中性示例；实际界面会让用户自行选择“你”或“妳”，并在后续直接称呼用户的文案中沿用该选择。

## 一、当前需要复核的内容

### 1. 跨页面核心选项

以下词语分别用于不同页面，不会作为一组选项同时出现：

| 页面与用途 | 当前候选文案 |
|---|---|
| Page 2 · 过夜期待 | 好好休息 |
| Page 2 · 过夜期待 | 多一点交流 |
| Page 2 · 在意 | 担心对方推进得比我愿意的更快 |
| Page 2 · 安心条件 | 我想保留一点自己的空间 |
| Page 4 · 独立行为 | 接吻 |
| Page 4 · 独立行为 | 插入式性行为 |
| Page 5 · 动机辨认 | 想更了解自己此刻的感受 |
| Page 5 · 隐私偏好 | 我希望这些内容只留给自己 |
| Page 7 · 健康入口 | 查看与所选行为相关的健康准备 |

请重点确认：

- “插入式性行为”是否足够中性、易懂；是否需要在展开说明中区分阴道插入、肛门插入以及可能使用的身体部位或物品，以便匹配不同健康信息。
- “担心对方推进得比我愿意的更快”是否自然，并能覆盖催促、压力与勉强，而不预设伴侣一定会伤害用户。
- 这些表达是否分别适合作为期待、担忧、动机、安心条件和健康入口。
- 是否存在异性恋中心、插入中心、羞耻化或把共同过夜默认等同于性行为的问题。
- “你／妳”两种替换版本是否都自然；不再要求全局只能选择其中一个。

### 2. 核心知识卡

请确认标题和正文是否准确、安全，并且不会构成针对个人的医疗建议。

#### 留意身体，也听见意愿

> 放松、紧张、兴奋、疼痛或想暂停，都是可以留意的感受。身体反应不能替你回答是否愿意，也不能代替明确沟通。

#### 同意需要持续确认

> 同意需要针对具体行为、持续存在，并且可以在任何时刻改变或撤回。沉默、僵住、没有反抗或此前同意，都不代表此刻同意。

#### 与行为相关的健康准备

> 不同身体接触涉及的健康需求不同。根据自己可能选择的行为，查看适用的避孕、屏障保护、性传播感染检测和何时寻求专业医疗帮助等信息。

请重点确认：

- “放松、紧张、兴奋”等身体感受不会被误读为判断同意的标准。
- “沉默、僵住、没有反抗不等于同意”的表述是否准确、适龄且符合创伤知情原则。
- “具体、持续、可以撤回”是否完整表达同意原则。
- 健康卡是否清楚说明并非每种行为都涉及避孕或相同的感染风险，具体内容必须按行为呈现。
- 是否需要在卡片层级直接加入“若疼痛频繁、程度较重或持续存在，应咨询医疗专业人员”。

### 3. 预设表达练习

请确认以下句子是否自然、容易说出口，同时保持边界清晰。句子按需要分类，而不是按“越来越严重”的路线排列。

1. **放慢进度**  
   我感觉现在推进得有点快，我有些不安心。我们可以慢慢来吗？
2. **调整动作速度或力度**  
   我感觉这样有点太快了，我们可以慢一点、温和一点吗？
3. **暂时停下**  
   我现在感觉有些不对，可以先休息一下，过一会儿再决定要不要继续吗？
4. **这次不再继续**  
   我感觉不太舒服，我们这次就到这里吧。
5. **换一种方式**  
   我们可以换一种方式吗？我现在更想要……
6. **还不知道接下来想怎样**  
   我感觉不太舒服，可以先停下来，让我仔细感受一下吗？

全局强调语：

> **暂停不需要道歉。**

请重点确认：

- “这次不再继续”是否足够明确，不容易被理解为继续协商。
- 是否需要为高压力情境补充更直接的短句，如“我现在不想继续”“停下来”“请不要碰我”。
- 温和版本与直接版本应作为不同情境下的可选表达，而不是要求用户先温和、无效后才能直接。
- 所有句子均不加入“对不起”，也不把安抚或照顾对方情绪作为表达边界的前提。

### 4. 对方回应与安全分支

请分别复核以下四种情况。产品不会默认伴侣会伤害用户；后三项只在用户主动进入“不理想回应预演”时出现。

#### A. 支持并尊重边界

对方：

> 好，我们先停。你不需要现在决定下一步。

#### B. 感到失望，但仍然尊重边界

对方候选文案：

> 我有一点失落，但好，我们先停下来。

用户可选择不再回应；如想回应，可使用：

> 我知道你可能会失望，但我现在不想继续。

请确认这句是否仍让用户承担了过多照顾对方情绪的责任；如是，请提供更合适的替换。

#### C. 质疑改变或继续施压

对方候选文案：

> 你刚才不是还愿意吗？我们都已经到这里了。

用户候选表达：

> 我已经改变主意了。现在停下来。

提示候选文案：

> 你不需要继续解释或说服对方。如果对方继续施压，可以结束这次互动，优先照顾自己的安全。

#### D. 忽视暂停、拒绝或阻止离开

> 普通情境练习在这里结束。优先离开当前互动，前往更安全的地点，并联系可信的人；如有紧急危险，请联系所在地的紧急服务。

请重点确认：

- B 与 C 的边界是否清楚，即“有失望情绪但停止”不同于“质疑、纠缠或继续施压”。
- C 出现后是否还适合提供一次直接表达练习，以及在什么节点应结束普通练习。
- D 是否应立即终止普通练习流程，不再要求用户继续解释、协商或安抚对方。
- 安全提示是否需要按服务地区补充正式的紧急服务、性暴力支持或可信机构信息。
- 情境文案是否避免暗示用户需要为对方的行为负责。

### 5. 当前来源候选

以下链接、机构与适用内容已经完成基础核对，但 **CAVE 的中文转述仍待医学或性教育专家批准**。请确认来源是否适用、是否足以支持对应表述，并指出需要补充的中文或本地化来源。

#### 同意、边界与身体自主权

1. [Consent 101: Respect, Boundaries, & Building Trust](https://rainn.org/share-the-facts/consent-101-respect-boundaries-and-building-trust/) — RAINN；适用于独立、持续、可撤回的同意，以及身体反应不等于同意。RAINN 为美国机构，不将其危机热线或法律信息直接用于其他地区。
2. [International technical guidance on sexuality education](https://cdn.who.int/media/docs/default-source/reproductive-health/sexual-health/international-technical-guidance-on-sexuality-education.pdf) — UNESCO、WHO 等；面向全球性教育框架，适用于 15—18+ 岁的同意、隐私、身体完整性与表达技能。
3. [Comprehensive sexuality education](https://www.who.int/news-room/questions-and-answers/item/comprehensive-sexuality-education) — WHO；适用于准确、适龄的性教育以及身体自主权原则。

#### 性健康与防护

1. [Condoms](https://www.who.int/news-room/fact-sheets/detail/condoms) — WHO；全球公共卫生资料，适用于安全套与大多数性传播感染、HIV 和非意愿妊娠风险降低的说明。
2. [Sexually transmitted infections (STIs)](https://www.who.int/news-room/fact-sheets/detail/sexually-transmitted-infections-%28stis%29) — WHO；适用于性传播感染预防、屏障保护的作用与局限，以及 HPV、乙肝疫苗信息。
3. [Birth Control](https://www.acog.org/womens-health/faqs/birth-control) — American College of Obstetricians and Gynecologists；适用于避孕与性传播感染预防的区分，以及安全套、口交膜等屏障方法。其医疗服务语境主要面向美国，需要评估本地化表述。
4. [When Sex Is Painful](https://www.acog.org/womens-health/faqs/when-sex-is-painful) — American College of Obstetricians and Gynecologists；适用于性活动疼痛频繁、严重或持续时的求医提示。

请为每个拟采用来源确认：

- 来源名称、机构与公开链接准确。
- 适用人群或地区及其限制。
- 是否足以支持 CAVE 对相关原则的简短转述。
- 是否需要补充中国大陆或中文地区的权威来源。
- 页面所列发布日期或最近更新时间；若来源未注明，应保留“页面未列明”，不能猜测。

来源审核需要覆盖：

- 同意可以随时改变或撤回。
- 身体反应、沉默或没有反抗不能代替明确同意。
- 插入式性行为及其他相关身体接触的避孕、屏障保护、性传播感染和求医信息。
- 忽视拒绝、持续施压或阻止离开时的安全建议。
