## 旅程 01 认识身体

01 先讲亲密相关的基础身体知识，不要求观察或触摸身体，也不要求完成亲密行为。内容按“名称与位置、外观差异、身体反应与意愿”展开。乳房及其他身体区域只作简短提示，具体亲密方式留给 02。

### 外阴、阴道在哪里？

> 外面看得见的生殖器区域叫外阴。阴道在体内，开口是阴道口。外阴上还可以看到阴唇、阴蒂和尿道口。

沿用现有的 `assets/medical/vulva-anatomy-review-current.png`。初次进入时显示淡紫色提示卡，用户点“确认点开”后才展示中央解剖图，图下可点“隐藏图片”；1–7 的中文部位名称和中文说明始终可读。图中原有两侧中文标签不显示，2、4 数字圈左侧与 1、3、5、6、7 数字圈右侧多出的连线在界面中遮盖。说明依据 [ACOG 外阴与阴道健康资料](https://www.acog.org/womens-health/faqs/vulvovaginal-health)、[Newcastle Hospitals NHS 外阴自检指南](https://www.newcastle-hospitals.nhs.uk/resources/self-examination-of-the-vulva/)及 [University Hospitals Sussex NHS 外阴资料](https://www.uhsussex.nhs.uk/wp-content/uploads/2022/08/Vulva-cancer-and-vulval-surgery.pdf)编写；肛门在图中用于定位，但不属于外阴。图片及说明仍待专业复核，状态见[内容来源台账](source-registry.md)。图旁如何补充阴蒂的体内结构仍待确认。

### 每个人的样子都不同

> 阴唇的长短、颜色和左右形状可以不同；乳房的大小和形状也因人而异。示意图用来认位置，不代表每个人都长这样。如果有持续疼痛、瘙痒或明显的新变化，可以咨询医护人员。

正文下方附 ACOG《外阴与阴道健康》的简短中文导读。一个两行链接同时显示“阅读中文简述：外阴与阴道健康”及“参考自美国妇产科医师学会（ACOG）的患者资料”，通往官网 `/vulvovaginal-health/` 中文概述页。该页末尾再提供 ACOG 英文原文链接。官网概述是 CAVE 撰写的简述，不是对原文的全文转载；仍待专业复核，暂不编入生产 sitemap。

### 身体反应与我的选择

> 听到情话，或在拥抱、爱抚、亲吻等身体接触时，身体可能变得敏感，阴道口附近可能有分泌物、感觉湿润；也可能没有明显反应。阴道分泌物平时也会出现。这些只是你身体的反应，而你心里可能是舒服、好奇、犹豫或不适。身体反应不能替你决定是否愿意，这个决定也可以改变。

正文末尾增加一行链接，通往官网 `/body-response/` 中文译述页。该页以 NHS 的 *Understanding arousal* 为主要英文原文，结合 NHS 日常分泌物资料及 RAINN 同意原则；页末附英文原文链接。中文网页仍待专业复核，暂不编入生产 sitemap。

## 旅程 02 认识愉悦的方式

02 沿用三页翻页结构。第一、三页收束主题；第二页放并列、可自由展开的知识卡。用户不必读完所有卡即可继续，不要求尝试、回答或打卡；重新进入从第一页开始，不生成回顾记录。卡片不按强度或“进阶”排序。

### 第 1 页：亲密没有固定顺序

> 亲密可以是亲吻、拥抱和触碰，也可以包括其他身体接触。没有哪一种方式更“完整”，也不需要按顺序尝试。同一种接触，有人喜欢，有人无感，也有人不舒服；自己的感受也可能改变。接下来可以自由查看知识卡，只需了解，不要求尝试。

### 第 2 页：认识不同的亲密方式

> 这些方式并列呈现。可以自由点开感兴趣的卡片，不必读完每一张才能继续。

| 卡片 | 内容 |
|---|---|
| 亲吻与身体触碰 | 拥抱、亲吻、抚摸或身体贴近，都可以单独成为亲密方式，不需要通向阴道纳入。有人喜欢其中一些接触，也有人此刻不想被碰。先问对方愿意怎样接触、哪些部位不想被碰。乳房和外阴的具体触碰留在各自的卡片里说明。 |
| 乳房刺激 | 乳房或乳头的触碰，对不同人的感受差异很大，可能舒服、无感或疼痛。触碰前先确认对方是否愿意，以及喜欢怎样的接触。任何时候都可以停下，不需要说明理由。 |
| 手指触碰外阴 | 用手指触碰外阴，例如阴唇、阴蒂及其周围。不同部位的感受可能不同，也可能没有愉悦感。先确认对方是否愿意、哪些部位可以触碰。接触前保持手部清洁。无论是疼痛、不适、犹豫，还是只是想停，都可以随时停止，不需要说明理由。 |
| 口交 | 用口唇或舌头接触伴侣的生殖器。有人喜欢，也有人不想要这种接触。先确认双方是否愿意。口交也可能传播性传播感染；屏障方法可以降低风险。 |
| 阴道纳入 | 手指、阴茎或适用的性玩具进入阴道，与触碰外阴是不同的选择。先确认是否愿意。阴茎进入阴道时，需要考虑怀孕和性传播感染风险；频繁或严重疼痛值得咨询医护人员。 |
| 独自探索（可选） | 独自触碰自己的身体，了解喜欢、不喜欢或没有感觉的部分；也可以完全不做。没有必须达到的结果。接触前保持手和用品清洁。 |
| 肛门纳入（展开补充） | 手指、阴茎或适用用品进入肛门。它不是其他方式之后的“下一步”。这类接触可能造成微小损伤，也有性传播感染风险；具体保护事项在旅程 04 展开。 |

页底共通提示：**任何时候、出于任何原因，都可以暂停或停止。** 具体保护条件与双方约定留给 04。来源包括 SRC-005、SRC-006、SRC-007、SRC-014、SRC-017、SRC-018、SRC-019；中文改写仍待专业复核。

### 第 3 页：选择可以留给自己

> 了解一种方式，不等于必须尝试；喜欢一种方式，也不等于同意其他方式。可以说出自己的想法，也可以犹豫或改变主意。任何时候、出于任何原因，都可以暂停或停止。下一段旅程再练习如何发出邀请、回应犹豫与拒绝。

## 旅程 03 内容方向

先介绍怎样清楚、低压力地表达想靠近，以及怎样回应对方的犹豫或拒绝。主要篇幅放在被拒绝后的失落、尊重对方的选择、照顾自己，以及双方愿意时如何重新交流。03 聚焦亲密前的邀请情境；亲密后的误解与交流留给 06。内容以知识和短对话示例为主。

## 2026-10-15 旅程 03—06 实现

03—06 的三页正文与可展开卡片位于 `apps/mobile/src/features/explore/later-journeys.ts`。04 和 06 的末页使用同一张个人偏好卡，五个可选字段分别是愿意了解或尝试的方式、暂时不想要的方式、保护条件、暂停表达方式和事后照顾。偏好卡只供本人编辑，不代表对任何一次接触的预先同意；原生构建按账号存入本机加密数据库，Expo Go 仅在当前会话内保存。05 的实用卡包含舒适与清洁、保护意外、检测与求助，并链接 NHS 资料。03 与 06 的同意和交流原则参考 SRC-003；04 的保护内容参考 SRC-017、SRC-021；05 的健康提示参考 SRC-022 至 SRC-024。01 的镜子观察建议参考 SRC-020。各段中文改写仍待专业复核。
