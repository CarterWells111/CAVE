# 威胁模型

## 范围

当前产品的主要信任边界是 iOS 设备及 Keychain、移动端 JavaScript 包、Cloudflare Worker、D1、Resend、构建服务、GitHub 和日志系统。移动端只通过远程服务完成邮箱身份操作；旅程、沟通卡、手记和回顾正文停留在设备内。

仓库另有未接入移动端的 AI gateway。涉及模型提供方、Prompt 和练习文本的威胁只适用于独立研究接口，不代表当前 App 的数据流。

## 风险、控制与验证

| 风险 | 可能影响 | 当前控制 | 主要验证 |
| --- | --- | --- | --- |
| 本地数据库或密钥泄露 | 攻击者读取私密记录 | 原生 SQLCipher、设备级 SecureStore、无明文降级、密钥不进入日志或包 | 数据库、密钥生命周期和导出包扫描测试 |
| 密钥缺失或 schema 异常导致数据丢失 | 应用用空数据覆盖仍可恢复的资料 | 密钥/数据库不匹配和 schema 降级均失败关闭；迁移在独占事务中只向前执行 | 并发初始化、迁移回滚、错误密钥和高版本 schema 测试 |
| Expo Go 被误认为安全持久化 | 用户以为数据已加密保存 | Expo Go 明确使用内存运行时；原生能力只在原生构建中启用 | 运行时组合与配置测试 |
| 日志泄露邮箱、令牌或正文 | 运维日志暴露身份或私密内容 | 元数据白名单、敏感字段拒绝、请求 ID 格式限制、提供方错误正文不映射 | 日志脱敏和敏感 canary 测试 |
| 邮箱枚举与验证码滥用 | 暴露账号存在性、骚扰邮箱或暴力猜码 | 统一响应形状、10 分钟有效期、5 次锁定、邮箱和设备双重限流、幂等邮件请求 | 身份服务、路由、邮件适配器和迁移测试 |
| Refresh Token 重放或并发刷新 | 会话被复制或分叉 | 类型隔离的不透明令牌、摘要存储、移动端 single-flight、条件轮换、重放撤销 | 身份服务、D1 仓储和 AuthProvider 竞态测试 |
| 未经新验证删除账号 | 过期会话或被盗 Access Token 删除账户 | 有效会话、匹配邮箱、新验证码、一次性 5 分钟删除授权和幂等收据 | 账号删除服务、路由和移动端界面测试 |
| 深链绕过成年声明 | 未完成自我声明即进入受限内容 | 所有正式旅程路由统一检查本机声明；无声明时返回公开落地页 | 路由、门禁和生产流程集成测试 |
| 沟通卡意外外泄 | 未选择或待复核内容进入剪贴板/照片 | 冻结导出模型、分享状态过滤、复制和保存分别确认、照片仅添加权限 | 沟通卡派生、分享策略和图片适配器测试 |
| 删除中断留下数据库旁路文件 | WAL/SHM、密钥或会话残留 | 待删除标记、数据库操作协调、启动续删、完整清除数据库及旁路文件 | 删除全部数据和中断恢复测试 |
| 未审核内容进入生产 | 医学或教育表述被误认为已获认可 | 来源与复核状态进入结构化内容；生产校验拒绝非正式复核状态 | 内容 schema、来源和多模式校验测试 |
| 依赖或构建链被污染 | 恶意包、Action 或嵌入凭据进入产物 | 锁文件、Dependabot、CodeQL、生产依赖审计和导出包秘密扫描 | CI、配置测试和 fail-closed 扫描器测试 |

## 独立 AI gateway 的额外控制

研究接口对请求体使用大小限制和严格 Zod schema，并通过确定性安全分类、终止状态和输出约束阻止胁迫式继续、Prompt 泄露以及诊断或法律结论。请求正文和提供方响应不进入日志或 D1。

这些控制仅证明独立接口的防护设计。当前移动端不调用它；未来接入仍需要用户授权、资料范围选择、撤回、期限和专业转介等产品层控制。

## 仍需外部验证的事项

- 真实设备上的 SQLCipher/Keychain 持久化、升级和中断恢复。
- VoiceOver、大字号、系统键盘、照片权限和 iCloud 行为。
- 生产邮件送达率、域名信誉、D1 迁移和实时日志 canary。
- 专业内容复核与真实使用场景的安全评估。

未完成这些验证时，不应声称已通过医学审核、已完成全部真机安全验证或已经具备正式发布条件。
