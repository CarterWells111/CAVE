# 数据分类与保留

数据分类是代码和运维共同遵守的边界。任何新字段在实现前都应明确存储位置、保留期限、删除路径和日志策略。

## 当前产品数据

| 分类 | 示例 | 允许位置 | 保留与删除 |
| --- | --- | --- | --- |
| 公开内容 | 产品名称、课程与场景文案、来源元数据、公开版本号 | 移动端包、官网、Worker、GitHub | 随应用版本管理；内容审核状态必须一同保留 |
| 本机私密 | 旅程答案与进度、沟通卡、回顾版本、手记、重点提要、本机头像和偏好 | Development、Preview 与 Production 构建的 SQLCipher 数据库、SecureStore、App 管理的文件目录 | 保留到用户逐条删除、删除全部本机数据或卸载 App；按账号 UUID 分区，不提供云端恢复 |
| 开发预览本机私密 | Expo Go 中按账号隔离的手记、后来和阶段回顾；仅在用户明确存入手记时包含冻结沟通卡快照 | Expo Go 项目沙箱中的专用明文 SQLite `cave-expo-go-journal.db` | 不使用 SQLCipher，不适合录入真实敏感内容；跨进程重启保留，但卸载 Expo Go、清除项目数据或主动删除后不可恢复；旅程草稿和实时沟通卡等其他 runtime 数据不进入该库；从不上传 |
| 本机运行状态 | 成年自我声明、待删除标记、数据库密钥、安装令牌、Expo Go 手记清理标记和已清空账号 UUID tombstone | 设备 SecureStore；Expo Go 明文手记数据库的无正文元数据表 | 只服务门禁、恢复、安全删除或限流；Expo Go 清理标记与删除原子提交，仅在确认 WAL 非 busy 且已截断后清除；tombstone 防止页面或进程重启后误报账号手记仍被保留；不含正文、邮箱、令牌或卡片内容，从不上传 |
| 云端匿名身份 | 账号 UUID、带密钥的邮箱索引、验证码和会话摘要、次数、有效期、限流桶、删除授权 | Gateway D1 | 按各自有效期清理；删除云端账号时级联删除相关身份记录；不保存原始邮箱或本机私密内容 |
| 本机会话身份 | 登录后的标准化邮箱与 Refresh Token | 移动端内存、设备 SecureStore | 邮箱与本地 Refresh 会话一同保留到退出、会话清除、账号删除或删除全部本机数据；不写入 D1、日志、分析、错误正文或支持材料 |
| 短暂身份 | 一次性验证码、投递中的标准化邮箱 | 移动端内存、Worker 内存、Resend 投递请求 | 只在用户请求登录或删除验证码时处理；验证码不写入本机持久层，二者都不写入 D1 或应用日志 |
| 瞬时敏感 | 当前请求正文、模型响应、提供方响应正文 | Worker 与模型提供方处理单次请求时的内存 | 当前移动端未接入 AI Gateway；Gateway 不保存正文，也不将正文写入日志或指标 |
| 机密 | 邮箱索引密钥、验证码摘要密钥、Resend 凭据、数据库密钥、刷新令牌 | Worker Secret、设备 SecureStore | 不进入移动端公开环境变量、GitHub、分析系统、错误正文或支持材料 |

Access Token 只驻留移动端内存。Refresh Token 原文只保存在 SecureStore，D1 保存单向摘要。登录后的邮箱用于本机账户界面和会话恢复，但不会被写入私密内容表或用作云端内容索引。

## AI 研究接口中的瞬时数据

独立 AI Gateway 能够处理一次请求中的练习文本，但当前移动端没有调用该接口。只有其他经过明确配置的客户端主动请求时，文本才会短暂经过 Worker 和模型提供方内存。

Gateway 不把请求正文、模型响应或卡片写入 D1，也不把它们加入日志或指标。未来移动端接入 AI 前，仍需增加用户可见的数据授权和撤回机制；本节不代表当前 App 已启用 AI。

## 本地存储规则

- 原生构建使用 SQLCipher；数据库密钥在查询 schema 前加载，不提供明文降级。
- Expo Go 仅将手记、后来和阶段回顾写入专用明文 SQLite；旅程、沟通卡等其他 runtime 继续使用进程内存。首次进入手记必须提示该开发预览边界。
- Expo Go 与正式安装包属于不同数据沙箱。同一邮箱不会在二者、不同设备或不同安装间搬运手记；跨沙箱恢复需要未来单独审核的用户主动上传、导出或导入设计。
- 同一 Expo Go 安装中，重新登录同一云端账号会取得相同 `accountId` 并恢复该账号的本机手记；切换账号不会混看。删除云端账号后保留的旧手记保持锁定，同邮箱重新注册产生的新账号不会自动取得旧记录。
- 密钥或数据库缺失、密钥无效、SQLCipher 不匹配和 schema 降级都会停止打开，不自动删除残留资料。
- schema 迁移连续、只向前并在独占事务中原子执行。
- 登录、退出和删除云端账号不会自动删除本机私密内容；删除本机内容也不会自动删除云端账号。

## 导出与删除

- 沟通卡只有在用户分别触发复制或保存图片后才离开 App。
- 导出只包含用户选择分享、无需复核且未删除的字段，并带固定的同意提示。
- 照片路径只请求 iOS 添加权限，不读取相册；系统剪贴板和 iCloud 的后续行为由设备设置决定。
- 原生构建删除全部本机数据时会等待数据库操作结束，再清除密钥、数据库及 WAL/SHM、安装令牌、本机会话和待删除标记。
- Expo Go 删除手记时启用 SQLite secure delete，并在事务提交后验证 `wal_checkpoint(TRUNCATE)` 的 `busy=0` 且无剩余日志帧；未完成时保留无正文清理标记并阻止云端账号删除，直到安全清理成功。
- 删除操作可在中断后继续，重复执行不会恢复已删除内容。
