# 当前限制

内界 CAVE 当前是黑客松期间完成并持续完善的产品原型。以下限制用于明确产品边界，不代表后续承诺或发布时间。

## 内容与专业支持

- 来源台账中的机构、标题和链接已经核对，但部分中文改写仍等待医学或性教育专家复核。
- 内部演示内容校验不等于医学认可。产品不提供诊断、治疗建议、法律意见或危机干预。
- 医学示意图仍处于复核状态，不能仅凭免责声明进入公开生产内容。

## 数据与设备

- 私密内容不提供云同步或跨设备恢复。删除 App、清除本机数据或设备损坏可能造成不可恢复的数据丢失。
- Expo Go 只有手记、后来和阶段回顾使用按账号隔离的明文 SQLite 并跨进程重启保留；旅程和沟通卡等其他 runtime 仍是内存预览。该路径不使用 SQLCipher，只适合开发预览，不应录入真实敏感内容。
- Expo Go 与正式安装包、不同设备和不同安装属于独立数据沙箱；即使登录同一邮箱也不会互相看到本机手记。
- 自动化测试不能替代真实设备上的 Keychain、数据库迁移、照片权限、VoiceOver、大字号、冷启动和中断恢复检查。

## 账户

- 邮箱账户用于会话管理和同一设备上的手记隔离，不代表私密内容已经上传或备份。
- 云端账户删除与本机数据删除互不替代，需要用户分别执行。
- 云端账号删除后选择保留的本机手记保持锁定；同一邮箱重新注册会得到新的账号身份，旧记录不会自动改属。
- 邮件投递、域名信誉和生产 D1 状态依赖外部服务，需要持续运维检查。

## AI

- 当前移动端沟通练习完全使用预设分支，没有调用生成式 AI。
- 移动端已经接入可选的手记 AI 和旅程问答界面，以及 Gateway 鉴权、限流、模型适配和输出检查。每次请求单独预览和确认，不提供持续读取历史的授权。
- DeepSeek 服务端已配置并部署，固定旅程问题的真实调用已通过；本机模拟与自动化测试仍不能替代手机体验或全部场景的模型质量验收。
- 本机模拟不发送文字，仅用于操作流程验收；服务端 mock 模式明确返回无真实 AI，不冒充模型回答。
- 安全规则与输出检查降低风险，不能保证模型永远不误判或误答。现有旅程知识尚未全部通过专业复核，专业问答按资料审核状态限制。
- Expo Go 可检验上述 JavaScript 界面与网络流程，但不能替代 SQLCipher 和原生安全能力的设备验收。任何新的 development build 都须用户核对平台账号并明确批准。

## 平台与发布

- 当前原生安全配置和主要交付目标以 iOS 为主；Android 没有同等发布结论。
- 官网和后端可独立部署，但仓库中的构建成功不自动代表商店审核、正式发布或所有生产链路均已完成验收。
