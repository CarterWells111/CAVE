# 产品概览

内界 CAVE 面向希望改善身体认知、亲密沟通与自我边界的成年女性。以内界手记为核心，帮助用户记录容易忽略的感受、需要与边界，通过“后来”和阶段回顾看见变化。系统旅程提供辅助探索，不替用户判断“应该做什么”。

## 进入旅程

App 默认显示旅程首页，底部依次为旅程、内界手记、AI、我的。手记的阶段回顾保留在手记内，旅程历史保留在我的，不再设置独立回顾页。用户开始手记时需要完成 18 岁以上自我声明及邮箱登录，无须先阅读旅程前言。进入系统旅程时再按需阅读前言并选择称呼。声明不收集生日、证件或真实身份，也不构成年龄核验。

正式旅程共五页：

1. **身体与安全知识**：提供带来源状态的基础教育内容。
2. **过夜期待**：记录用户对一次共同过夜或亲密相处的期待与担忧。
3. **行为地图与边界**：为不同情境选择期待、熟悉、到时再决定、不确定或这次不想等并列态度。
4. **你随时可以改变主意**：确认当前感受并非必须履行的承诺。
5. **私密准备与沟通草稿**：从用户自己的选择推导沟通卡，区分愿意分享和只保留给自己的内容。

**预设沟通练习**是独立入口，也可以在旅程完成后进入；练习暂停、拒绝和改变主意，使用确定性预设分支，不使用生成式 AI，不计入五页进度。

用户可以返回修改、暂时退出并恢复草稿，或者明确重新开始。系统不生成准备度分数，也不根据选择给出关系或医疗结论。

## 沟通卡、回顾与手记

完成旅程后，用户可以编辑、保存、复制或保存沟通卡图片。任何离开 App 的导出都需要用户主动触发；需要复核、未选择分享或已删除的字段不会进入导出结果。

长期功能包括：

- 查看并编辑已保存的沟通卡。
- 保存回顾版本，从历史版本继续新的反思。
- 在“内界手记”中自由写一句话或使用逐题、可跳过的引导；标题与重点可以留空，由原文摘取。
- 自动保存按账号隔离的本机记录草稿；重新打开后恢复。
- 随时修改记录与“后来”，修改前的内容保留在历史中；删除记录时一并删除其历史。
- 选择最近一周、一个月或自选日期内的记录进行阶段回顾，从来源记录继续写“后来”。

## 账户与数据

核心旅程、练习、沟通卡和普通回顾不要求登录。内界手记需要邮箱验证码登录，目的是在同一设备上按账号 UUID 隔离手记和本地资料。

登录不会自动把旅程、手记、反思、练习、沟通卡或亲密内容上传到云端。AI 是单独的可选动作：每次预览并确认后，仅将当前或用户选定的文字及关联标识发送至内界 Gateway 与模型服务商 DeepSeek 处理。Gateway 不记录请求正文，也不保存手记。身份服务只处理邮箱验证码、账号和会话所需的最小元数据；原始邮箱不会写入 D1。产品不提供云同步，因此换设备、删除 App 或删除本机数据后无法从账号恢复这些内容。服务商保留/训练政策仍须在真实接入前核实，不承诺第三方零保留。

在同一 Expo Go 安装中，退出登录只清除会话。重新登录同一云端账号会取得相同 `accountId` 并恢复该账号的本机手记；切换到其他账号不会看到这些记录。

## 本地存储模式

原生构建使用 SQLCipher 数据库保存私密数据，密钥由设备 SecureStore 管理。数据库迁移只向前执行；密钥缺失、数据库不匹配或设备上的 schema 高于当前 App 时会停止打开，而不会用空数据库掩盖问题。

Expo Go 无法提供同样的原生安全能力。开发预览中只有手记、后来和阶段回顾写入专用明文 SQLite `cave-expo-go-journal.db`，并按 `accountId` 隔离；用户明确存入手记的冻结沟通卡快照属于该手记内容。旅程草稿和实时沟通卡等其他 runtime 仍只存在于内存。该明文库适合功能预览，不适合真实敏感内容，也不能作为 SQLCipher 真机验证证据。

Expo Go 与正式安装包属于不同数据沙箱。同一邮箱登录不会在二者、不同设备或不同安装之间同步手记；手记默认不上传，跨沙箱恢复需要未来单独设计的用户主动上传、导出或导入能力。

## 后续方向

产品可以从首次共同过夜继续扩展到同居、异地、健康告知、关系修复等常见沟通场景。已实现的可选 AI 接口覆盖继续写、整理、选定记录回顾和旅程问答；真实 DeepSeek 已接通并通过固定旅程问题的服务端验证，手机及全部场景仍需验收。AI 结果必须由用户采用后才能进入可编辑正文，不自动保存为用户事实。旅程专业知识仅引用通过审核的资料；当前可用范围以产品使用流程为主。不提供促成伤害的指导，不因用户记录受害或痛苦经历而拒绝其表达。

尚未完成的能力和验证边界见[当前限制](current-limitations.md)。
