# 友好聊天、自动批准与用量

## 交互

- 输入框不再要求选择手记或旅程。统一 chat 模式，模型结合用户消息、最近对话与服务端提供的公开旅程资料判断意图。
- 普通聊天直接返回自然文本；现有手记整理/回顾接口保持结构化输出及引用检查。
- 最近最多 6 轮（12 条、共 12000 字）作为上下文，只在当前会话内存中保存。发送确认逐条展示；可选择“这次仅发送本条消息”。不自动读取私人手记或图片。
- “帮我批准”是本次会话的可撤销选择，切换账号、退出会话/重启时重置。明确普通的寒暄、有限的公共知识提问可自动批准；个人信息、私人经历、敏感信息或不能明确识别的内容仍确认。判断发生在本机，不上传内容进行隐私分类。它是保守规则而不是通用隐私识别器。
- 仪表紧邻发送键左侧，按小时/每日中使用比例较高的一项显示指针，点击展示两项百分比、用量和当地重置时间。查询失败显示未知并可重试，不假装还有额度。

## 用量规则

- `ASSISTANT_HOURLY_LIMIT=5`、`ASSISTANT_DAILY_LIMIT=25`，按每账号调用次数计量，已写入 `wrangler.jsonc`。它们是可选正整数变量；其他环境未配置时显示“额度待设置”及实际次数，不产生虚假百分比。
- 使用次数是成功通过鉴权、输入检查和配额检查、进入 live AI 处理的请求数。之后模型失败或用户停止等待也计入，因为云端处理可能已发生。取消确认、非法请求、额度拒绝、本机模拟不计入。原有每分钟防滥用节流保留。
- 同一账号跨设备共享。一个 SQLite UPSERT 同时检查并增加小时与每日计数；并发请求不会分别扣计两项。
- 固定 UTC 时钟小时及 UTC 日期窗口，整点/零点重置；弹窗以设备当地时间展示。不是滚动 60 分钟 / 24 小时窗口。
- 仅保存账号关联和计数、窗口起点，一账号一行；删除账号时级联删除，不保存问题、回答或手记正文。

## 安全策略

聊天不再使用旧旅程知识白名单作为话题边界，也不使用“羞耻”“疼痛”等词直接拒答。系统指令区分日常/教育讨论、受害和痛苦表达，以及寻求实施伤害的请求；拒绝后者的危险操作细节，并尽量提供相关的安全替代。保持不冒充医生、不编造记忆、不制造排他依赖等边界。上下文只能包含 user / assistant 角色，不能注入 system 角色。

安全依赖模型遵守上下文指令，并非绝对保证。本次四个合成真实模型样本分别验证普通闲聊、同意与边界科普、非紧迫痛苦支持、暴力操作拒绝；发布后仍需持续评估，不把小样本当作全面安全认证。

## 部署与回退

1. 核对小时/每日次数变量；默认 5 / 25，调整需同步产品说明。
2. 在已确认 Cloudflare 账号核对备份与待执行迁移后，应用 D1 migrations，包括 `0003_assistant_usage.sql`。已有 `0002_account_preferences.sql` 也应核对是否已应用。
3. 再部署 Gateway；新表不存在时请求会失败关闭，不能先部署再迁移。
4. 确认鉴权后的 `/v1/assistant/usage` 返回计数，再更新客户端。旧客户端的 guide/summarize/review/journey 请求仍兼容；新客户端 chat 需要新版网关。
5. 手机检查：普通聊天、私密确认、自动批准撤销、额度达到上限、跨设备共享、整点重置，以及大字体/键盘弹出时仪表与发送键布局。

回退：先回退客户端，再把 Worker 回到 `85d6f516-971a-44e7-b955-aa6626f6f953`。新表是附加表，可暂时保留，避免删除计数数据；旧 Worker 不使用它。不要把临时合成测试入口发布为正式入口。

## 2026-09-09 已确认配置
用户结束五次试聊后，按现有调用次数口径确认每小时 5 次、每天 25 次。0002/0003 已迁移，友好聊天、计量与额度已部署，Worker 版本为 `38e3c63b-d587-4ba6-aa0d-1a3f8337359a`。输入框左下角提供“帮我批准”开关，可能私密的内容仍确认。费用样本见 [试聊用量](chat-cost-sample-2026-09-09.md)。

模型日志只记录状态、耗时与上游返回的 token 数量（含缓存命中/未命中），不记录聊天正文或凭证。开发版可显式设置非秘密的 UUID `EXPO_PUBLIC_AI_MEASUREMENT_ID` 来关联一次测量；构建版不会携带该标记。用量日志不是账户扣费账单，缺失 usage 的失败/取消请求不能按零费用处理。
