# 内界 CAVE｜Demo Day 展示简稿

> 版本：讨论稿 v0.1｜目标：让评委在 3 分钟内理解问题、体验核心价值、相信产品真的能运行。

## 一句话定位

内界 CAVE 帮助成年人在第一次亲密过夜或难以开口的亲密沟通前，理解自己的期待与边界、练习表达，并整理成一张可以带进关系里的沟通卡；它不替用户作决定，也不给“准备程度”打分。

## 上午摆摊：3 分钟

**0:00–0:25｜先讲她的处境**

> 她期待第一次共同过夜，也担心拒绝会让对方失望。真正困难的不是“不知道该做什么”，而是不知道自己想要什么、又该怎样说出口。

**0:25–1:50｜只演示三个动作**

1. 在行为地图里，为一个具体行为选择“期待／到时再感受／不确定／这次不想”。
2. 在预设练习里说出“我想暂停”，看到一段尊重边界的回应。
3. 把自己的表达放进沟通卡，区分“可以分享”和“只留给自己”。

**1:50–2:25｜展示结果**

打开沟通卡，展示编辑、复制或保存图片。重点不是“生成了一张卡”，而是用户终于有了一段真正能开口的话。

**2:25–3:00｜为什么值得相信**

- 本地优先；核心旅程无需账号，内界手记登录仅用于本机账号隔离。Expo Go 版本仅作为现场原型，不声称已验证持久化加密。
- 所有态度并列呈现，不把亲密行为设计成升级路线。
- 用户可以暂停、改变主意、返回修改。
- 当前练习是预设对话，不使用生成式 AI。

## 下午舞台：4 分钟

- 0:00–0:30：人物与关系困境。
- 0:30–0:50：一句话定位和“理解自己 → 练习表达 → 沟通卡”闭环。
- 0:50–2:35：行为地图、暂停练习、沟通卡。
- 2:35–3:15：本地优先、非评分、安全边界与技术实现。
- 3:15–3:45：本次创作期的 0→1 增量与真实试用证据；没有完成访谈前不使用用户引语。
- 3:45–4:00：从第一次过夜扩展到同居、异地、健康告知和关系修复等困难沟通。

## 命题口径

- **Eazo**：从女性真实但长期被忽略的生活细节出发，做一个以前没人替她做过、她会真正使用和分享的 App。
- **萨福**：主打“关系中的细微、矛盾和说不出口”，争取关系洞察与观众共鸣；不把尚未接入 App 的 AI gateway 说成现成功能。

## 不主动展示或声称

- 不逐页讲完全部六页，不把设置、历史记录放入主线。
- 不展示待审核医学图和待专家审核内容。
- 不声称“医学认可”“已发布”“真机加密已验证”或“AI 驱动”。

## 需要一起确认

1. 开场人物用“第一次共同过夜”，还是换成更普遍的“关系中想暂停却难开口”？
2. 现场三个动作是否就是：行为态度、暂停表达、沟通卡？
3. 谁负责主讲、谁负责操作和补充技术问题？
